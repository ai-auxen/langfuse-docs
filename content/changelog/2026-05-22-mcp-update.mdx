With this update, Langfuse project data becomes directly available in MCP-compatible workflows. Agents can inspect observations, query metrics, manage scores, work with datasets, create comments, and operate on annotation queues without switching tools.

This opens up new workflows for using Langfuse in agentic development. For example, an agent can investigate a production issue, pull the relevant observation details, compare metrics, create or update scores, add comments for the team, or prepare dataset items for regression testing.

The goal is to make Langfuse data actionable where teams already work with AI agents: in IDEs, automation workflows, and custom internal tools. Instead of copying data between systems, agents can use Langfuse as shared context for debugging, evaluation, and continuous improvement.

This complements the [Langfuse CLI](/changelog/2026-02-17-langfuse-cli), which remains a good fit for terminal workflows, CI scripts, and direct access to the full Langfuse API. The hosted MCP server is optimized for MCP-compatible agents that benefit from structured tool discovery, typed inputs, and no local CLI setup. Together, they give teams two ways to make Langfuse available to agents: a command-line interface for shell-native automation and an MCP interface for agent-native workflows.
